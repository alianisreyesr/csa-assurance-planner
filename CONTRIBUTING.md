# Contributing

Thanks for helping improve this portfolio project.

1. Open an issue describing the problem or proposed change.
2. Create a focused branch from `main`.
3. Follow the setup and verification commands in the README.
4. Add or update tests for classification and lifecycle changes.
5. Open a pull request explaining the assurance impact, rationale, and verification performed.

Use synthetic scenarios only. Do not contribute proprietary, personal, employer, production, or regulated data. Report vulnerabilities through `SECURITY.md`.
