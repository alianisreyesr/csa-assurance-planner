## What this is

A structured planning system that models **Computer Software Assurance (CSA)** methodologies for software utilized in **medical device production or quality management systems** (QMS):

1. **Intended use:** Define system boundaries and operational process dependencies.
2. **Risk analysis:** Assess direct and indirect impacts on product quality and patient safety.
3. **Assurance activities:** Establish scripted tests, unscripted exploratory testing, and vendor verification evidence.
4. **Assurance record:** Generate audit-ready documentation and execution summaries.

Aligned with FDA Computer Software Assurance guidance: scaling testing rigor to risk rather than treating all software identically.

**Stack:** Python · FastAPI · Pydantic · SQLite · React · Docker · GitHub Actions
